## 🚀 Projects & Ideas

### 🍸 Waitr

**Waitr** is an app concept for connecting people hosting events with freelance hospitality workers.

Users could hire professionals such as:

- Bartenders
- Servers
- Barbacks
- Hosts
- Event staff

The platform could include scheduling, worker profiles, ratings, messaging, payments, and location-based job discovery.

The goal is to create an easy way for event hosts to find workers while giving hospitality professionals access to flexible work opportunities.
